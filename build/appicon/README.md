# Composer Bridge icons

Source SVG: icon.svg (Better Lyrics path, fill #F20C32)
Monochrome: icon-mono.svg (black) and icon-mono-light.svg (white, dark mode menu bar)

All raster assets are regenerated from the SVG via rsvg-convert. To rebuild after editing the SVG:

  ./scripts/regen-icons.sh

Color rule: this icon is Better Lyrics red. Never Composer brand accent.
